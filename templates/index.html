Connect your AI tutor

StudyAI can use Ollama to run a model on your computer, with no API key. Install it from ollama.com, then run:

ollama pull qwen2.5:3b

To solve questions from pictures, also download its vision model:

ollama pull llava:7b

Keep Ollama running while you study. Local model requests and your study progress stay on this computer.
